TaskFlow

TaskFlow — Full-Stack Task Management Web App (Go) TaskFlow is a focused, single-user task tracker built to bridge the gap between overly simple to-do lists and heavyweight project-management tools. It supports secure JWT-based authentication with instant logout revocation via a Redis-backed token blacklist, full task CRUD with priority levels and optional due dates, and Redis caching for faster reads. A standout feature is its daily completion streak system — a habit-forming feedback loop that tracks consistency, not just pending tasks — shown alongside a 14-day activity view. The app ships as a clean, framework-free dashboard styled like a wall of sticky notes, with filtering, search, and a CORS-enabled REST API. Built with Go, GORM, PostgreSQL, and Redis on the backend, and vanilla HTML/CSS/JS on the frontend.
